# Workflow — Industry Research

> **Layer:** 3 — Industry Framework
> **Status:** Concept frozen, implementation pending

---

## Framework Building Process

```
Step 1: Theme Selection
  ↓ Select industry theme from Research Terminal
Step 2: Initial Framework
  ↓ Build initial framework (supply/demand/drivers/variables)
Step 3: Event Integration
  ↓ Integrate relevant events from Daily Briefing
Step 4: Framework Evolution
  ↓ Evolve framework with new research findings
Step 5: Template Extraction
  ↓ Extract reusable analysis templates
```

## Framework Versioning

- Each industry has one Framework document
- Framework evolves: Version 1 → Version 2 → ...
- Version control via Git
- Changes must be recorded in CHANGELOG

## Quality Gates

- Must cover supply side, demand side, drivers, key variables
- Must be reusable (not one-time report)
- Must be referenced by Company Research
