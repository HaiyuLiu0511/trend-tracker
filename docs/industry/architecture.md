# Architecture — Industry Research

> **Layer:** 3 — Industry Framework
> **Status:** Concept frozen, implementation pending

---

## Data Inputs

- Theme list (from Layer 2 — Research Terminal)
- Related events (from Layer 1 — Daily Briefing)
- Public research data

## Framework Structure

```
Industry Framework
├── Supply Side Analysis
├── Demand Side Analysis
├── Key Drivers
├── Key Variables
├── Competitive Landscape
├── Industry Trends
└── Analysis Templates (reusable)
```

## Cross-Layer Interface

**Input from Layer 1-2:**
- Theme list (from Research Terminal)
- Related events (from Daily Briefing)

**Output to Layer 4:**
- Industry Framework (prerequisite for Company Research)
- Analysis templates

**Feedback from Layer 4-5:**
- Company Research findings feed back to Industry Framework
- Monthly Outlook evolves Industry Framework
