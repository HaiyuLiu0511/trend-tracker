# Architecture — Monthly Outlook

> **Layer:** 5 — Knowledge Evolution
> **Status:** Concept frozen, implementation pending

---

## Data Inputs

- All research records from past month (Layer 1-4)
- Investment Map (current state)
- Previous month's Monthly Outlook

## Processing Structure

```
Monthly Review
├── Cognitive Evolution (what understanding changed?)
├── Investment Map Update (add/remove/adjust)
├── New Themes (what new themes emerged?)
├── Framework Evolution (Industry Framework updates)
└── Feedback to Daily Briefing (next cycle focus)
```

## Cross-Layer Interface

**Input from Layer 1-4:**
- All research records from past month
- Current Investment Map

**Output:**
- Cognitive evolution record
- Updated Investment Mapping
- New theme identification
- Framework evolution notes

**Feedback to Layer 1:**
- Influences next cycle's Daily Briefing focus
- Knowledge evolution shapes what events are important
